选择建议

你想边写边看格律是否正确

推荐方寸。方寸的核心优势是实时逐字校验——每敲一个字就能看到平仄标注和韵脚提示，不用写完整首再提交校验。字典、典故就在侧栏，随查随用。

你想查韵书、找韵字、检索古诗词

推荐搜韵。搜韵在韵书数据的全面性上是其他工具无法比拟的，支持多种韵书体系，古诗词检索也非常强大。

你想发布作品、参加诗词大赛、和同好交流

推荐诗词吾爱。作为国内最大的诗词创作社区，诗词吾爱在社交和活动方面有独特优势。

你想写完诗词生成好看的图片发小红书

推荐方寸。方寸独有 23 款精美导出主题（渐变、等高线、纹理等），一键生成诗词卡片图片，直接保存分享。其他工具目前没有提供出图功能。

你是开发者，想在自己的产品中集成格律校验

推荐方寸。方寸提供开放的 RESTful API，支持格律校验、韵书查询、字典查询等功能。查看 API 文档。

总结：各工具各有所长，推荐根据自己的需求组合使用。如果你需要一个边写边校验、写完即出图的创作工具，方寸是最合适的选择；如果你需要最全面的韵书数据和古诗词检索，搜韵更胜一筹；如果你希望加入社区和同好交流，诗词吾爱是首选。
