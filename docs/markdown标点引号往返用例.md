# Markdown 标点覆盖 / 引号 往返用例

> 背景：产品侧确认「标点覆盖、引号不往返」需要修复 —— 用户手动设置的标点与「」《》“”‘’ 标记在 复制 Markdown → 粘贴导入 后丢失（标点退回校验默认、引号全部消失）。
> 修复：导入侧（`frontend/src/lib/markdownRoundTrip.ts` → `applyMarkdownImport`）逐字扫描粘贴文本，按字索引重建 `punctOverrides` / `auxMarks`，与导出侧对称。
> 验证：`cd frontend && npm run check:md`（本部分用例 S22–S27，全量 52 断言 + 3 已知限制）。

## 1. 修复原理（导入侧扫描规则）

对每一节的正文文本逐字处理，维护「当前字索引 j」（仅汉字/□ 推进）：

| 扫描到的字符 | 动作 |
|---|---|
| 汉字 / `□`（空位） | 写入 `poemChars[j]`；挂起的开引号写入 `auxMarks[j]`；j+1 |
| 开引号 「《“‘ | 挂起（等待下一个字） |
| 关引号 」》”’ | 追加到 `auxMarks[j-1]`（当前字） |
| 标点 ，。、；：？！ | `punctOverrides[j-1] = 该标点` |
| 换行 / 其余 | 跳过（律诗联间换行、跨联引号正确落位） |

数组语义与渲染一致：`auxMarks[i]` 为有序数组，开方向在前、关方向在后（如 `['「','」']`）；渲染按方向集合拆分到字前/字后。

## 2. 用例清单

| 用例 | 场景 | 输入（画板状态） | 预期 | 断言 |
|---|---|---|---|---|
| S22 | 手动标点覆盖往返 | 五绝，`punctOverrides{9:'，'}`（韵脚改逗号，与校验默认 。 不同） | 粘贴后 `punctOverrides[9]==='，'`，正文不变 | 覆盖保留、字序不变 |
| S23a | 引号跨联往返 | 「…」包住首联（开引号在字 0、关引号在字 9，中间隔律诗换行） | 开引号落 `auxMarks[0]=['「']`，关引号落 `auxMarks[9]=['」']` | 跨 \n 落位正确 |
| S23b | 嵌套引号顺序 | 「“X”」：`auxMarks{0:['「','“'], 4:['”','」']}` | 往返后数组顺序完全一致 | 开闭方向有序 |
| S24 | □ 空位 + 标点 + 引号混合 | 半成品（含 □），`punctOverrides{4:'，',9:'。'}`，`auxMarks{3:['《'],4:['》']}` | □ 位置不位移；标点/引号按字索引落位 | 混合场景不串位 |
| S25 | 粘贴清空旧覆盖 | 画板带旧 `punctOverrides{4:'！'}`、`auxMarks{0:['「']}`，粘贴无标点文本 | 旧覆盖/引号被清空（`undefined`） | 内容替换语义 |
| S27 | 全量对称 | 覆盖+引号+元数据的完整画板 | 导出→导入→再导出，两次 Markdown **逐字符一致** | 无损闭环 |
| S26 | 抑制标点（空串覆盖）不往返 | `punctOverrides{9:''}`（抑制韵脚标点） | 往返后抑制丢失、恢复默认（KNOWN 限制） | 已知限制 |

## 3. 用例详细说明

### S22 手动标点覆盖往返（核心诉求）
用户把韵脚处句号改成逗号（或其他非常规标点），复制 → 粘贴到新画板后，该处必须仍是逗号而不是被校验推回句号。
修复前：标点随文本被过滤，粘贴后该处显示校验默认 `。`（覆盖丢失）。
修复后：扫描到文本中字 9 后的 `，` → `punctOverrides[9]='，'`，渲染/导出/图片导出/上传全部读该覆盖。

### S23 引号标记往返
- a）**跨联**：律诗导出在联间插 `\n`，引号可能跨过换行（「床前明月光，\n疑是地上霜」）。扫描跳过 `\n`，开引号挂起到第一个字、关引号落在最后一个字。
- b）**嵌套**：「“X”」这类外层+内层引号落在同一对首尾字上时，数组顺序 `['「','“']`（开）与 `['”','」']`（关）必须原样保留——渲染按方向集合拆分，顺序即显示顺序。
- 注：`『』` 不是应用受支持的标记（UI 选择器仅「」《》“”‘’ 8 个），不参与往返。

### S24 混合落位
半成品（□ 空位）与标点/引号混排时，`□` 与汉字一样推进索引，保证其后的标点、引号、字都落在正确的格位上（此前的 □ 错位缺陷一并覆盖验证）。

### S25 内容替换语义
粘贴=整首替换：新内容没有标点时，旧画板残留的覆盖/引号必须清空，不能保留在新文本的字位上（否则会产生幽灵标点）。

### S27 无损闭环
带「覆盖+引号+作者+日期」的完整画板：首次导出的 Markdown 与「导入后再导出」的 Markdown 逐字符相等。这是往返一致性的最强断言——任何一侧不对称都会在此暴露。

### S26 抑制标点（KNOWN）
覆盖值为空串（UI「确认清除」标点）在导出文本中无对应字符，导入无法还原，恢复为校验默认。语义上不可无损，接受为已知限制。

## 4. 影响面备忘

- **代码**：仅 `applyMarkdownImport`（导入侧）；导出、渲染、校验、图片导出、上传、诗词库导入零改动。
- **行为**：粘贴后画板自带整份标点覆盖+引号标记（与「诗词库导入」行为一致）；此后若改韵结构，该处标点不随校验自动更新（与手动覆盖同语义，UI「恢复默认」可清除）。
- **兼容**：旧导出→新解析向后兼容；已存画板不受影响；`IMPORT_MARKDOWN` 本就可撤销。
